# HackaTownWebTemplate

==============================================



## 🛠 Steps to run locally:


1. **Install WebStorm**: dowload it (windows) [here](https://www.jetbrains.com/webstorm/download/download-thanks.html?platform=windows).
2. **Launch** it
3. on WebStorm clone this repo
4. once clonned, install node.js
5.  Open the terminal and run:
    ```bash
    npm install
    ```
6.  Then, install the Firebase dependency:
    ```bash
    npm install firebase
    ```
7. then get the "firebase.js"(api keys) and put it on root of project
8.  Start the development server:
    ```bash
    npm run dev
    ```
9. thats it, 
10.  Install xampp, mysql lts 9.7 and beekeeper! an put htdocs in xampp root!
